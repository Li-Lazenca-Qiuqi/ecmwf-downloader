# 产品现状

功能核对日期：2026-10-07；记忆系统入口同步：2026-10-23。版本：0.5.0。待办与阶段规划以 `.backlog/tasks/` 和 `.backlog/milestones/` 为准；历史证据见 [验收记录](note/acceptance_2026-10-07.md)，迁移实施说明由 Backlog 的 TASK-1 维护。本次没有重跑历史测试，也没有用户逐项验收结论。

## 定位与环境

本机单用户 ECMWF/CDS 下载管理工具，面向 Linux + Python 3.11+。Typer CLI 与 FastAPI/React 管理台共享应用服务、SQLite 数据库和独立凭据文件。Web CLI 只允许回环地址，无认证及多用户隔离，不支持局域网或公网部署。

## 核心流程

1. 配置 CDS 账号；密钥进入权限为 `0600` 的 `config/secrets.yaml`，公共账号 DTO 不返回密钥。
2. 指定 `dataset_id + request_payload`，预览输出路径和拆分结果，创建任务。
3. 任务入队，由 Web 内置 Worker 或独立 `ecmwf worker` 消费。
4. 文件写入 `.part`；成功后原子重命名，保存状态和事件。
5. 查看任务、请求取消，或在失败后重试。删除任务记录不删除下载文件。

## 已有能力

| 范围 | 当前实现 | 边界 |
| --- | --- | --- |
| 请求 | 任意对象 payload；不拆分、按年、按年月拆分 | 预览只证明本地格式和拆分通过，不证明 CDS 接受请求 |
| 任务 | pending、queued、running、completed、failed、retry_wait、cancelling、cancelled；查询、入队、取消、重试、删除及 API 批量操作 | 状态转换与事件写入 Repository 事务 |
| 调度 | 并发限制、调度器租约、任务心跳、启动时恢复过期任务 | 关停、租约切换及恢复时机仍有缺口，不能宣称可靠故障恢复 |
| 下载 | 通用 CDS adapter、`.part`、原子重命名、默认拒绝已有目标 | 重复任务相同路径的并发保护未完成 |
| 进度 | 下载期间记录文件字节；完成后为 100% | 总大小未知时为 null；没有可靠断点续传 |
| 账号 | 多账号选择、启禁用、成功失败计数、连接检查 | 连接检查不能替代真实下载和数据集条款验证 |

| 模板与设置 | CLI/API 模板 CRUD、非敏感设置更新、AI key 单独保存 | 现有 Scheduler 的并发与轮询参数没有完整热更新 |

| 同步 | SSE 事件及 Last-Event-ID 重连；前端查询失效刷新和定期轮询 | 活动页没有完整事件历史视图 |

## 管理台现状

提供概览、创建请求、任务队列、下载活动、账号池和设置页面。创建并入队、任务搜索、行内入队和取消、账号新增与编辑已接入 API。设置页主要展示配置。

仍有未接线或展示性控件：任务状态筛选、选择与分页、查看与更多操作、活动页全部入队与停止调度、请求重置与保存模板、账号搜索与规则编辑等。“仅创建任务”当前调用预览接口，并不会创建 pending 任务。服务、调度器、数据库和输出目录状态以及部分并发/重试数值为固定文案，不能视作实时健康证据。新增账号时选择的禁用状态尚未应用到新账号。

## 已知限制与风险

- 取消只在 `retrieve` 和 `download` 前后检查，不能立即中断远端排队或传输；不支持暂停。
- `stop()` 不等待运行中的下载线程就释放租约；失去租约后没有阻止旧 Worker 继续写入的机制。
- 过期任务只在启动时恢复；启动时任务租约尚未过期的遗留任务可能持续停在 running。
- 配置更新先写文件再校验，无效配置可能影响下一次启动；具体修复登记在 Backlog。
- 输出扩展名尚未完整考虑 `download_format=zip`。
- 正常账号响应不含 key，但异常、HTTP 校验错误和日志的全链路脱敏尚未验收。

0.5.0 使用全新数据库，不导入旧 YAML/JSON 历史，不自动删除旧配置或已有下载文件。截至本轮记忆迁移，没有新增真实 CDS 下载或科学内容检查通过证据；账号为空是 2026-10-07 的检查结果，不能推定为 2026-10-23 的实时配置状态。
