# ECMWF Downloader 产品说明

当前工作区定位：面向 Windows/Linux 的单用户 ECMWF/CDS 请求与结果链接管理工具，CLI 为主要入口，本地回环 HTTP 服务同源提供 API 和 Web，服务器通过 SSH 端口转发访问。当前版本号仍为 0.5.0；本轮没有发布新版本。

## 核心流程与边界

编辑科学参数 → 可选按年/月/日或目标份数拆分 → 自动提交 → 监视远端排队/处理 → 提供结果链接。
“链接已就绪”只表示远端作业成功并返回结果元数据，不表示文件已经下载。软件不读取科学数据文件体，不创建下载目录或 .part，不执行本地 NetCDF 导出，也不启动专业下载器或浏览器下载。
用户通过页面复制链接，或使用 CLI/API 获取 URL，再交给自己的下载器；软件不跟踪外部传输速度、进度或完成情况。data_format/download_format 仍是源站文件生成及封装参数。

## 数据来源

- CDS 为默认来源。目录使用官方公开 Catalogue API 完整分页，可按名称和 ID 搜索；进程缓存一小时。无账号可浏览目录，字段、约束、规模与提交需要可用 CDS 账号。
- CDS 使用 ecmwf-datastores-client 独立提交、查询远端作业和读取结果资产，显式 cleanup=False，不调用 retrieve/download，不在获取链接后自动删除远端作业。
- NCAR AWS ERA5 与 NCAR GDEX ERA5 各自列出真实目录，选择已发布原文件后返回 HTTPS 文件链接；使用 HEAD 获取可用响应头，不读取文件体，不需要 CDS 账号。
- NCAR 一个原文件对应一个链接任务，不提供区域裁剪、格式转换或年月日拆分。
- Google ARCO 本地读取 Zarr 并导出 NetCDF 的能力已移除，可提交来源不再包含 ARCO。raw 云文件或远端子集服务如需接入，须单独明确真实接口，不能用 Zarr 根地址冒充所选子集文件。

管理台四个页面与顶部导航的内容区域共用同一居中宽度。按可用视口宽度的 94% 伸缩，上限为 1360px。保留稳定的滚动条空间，避免切换页面时内容宽度跳动。

## 请求编辑

通用字段模型保留真实分组、互斥分支、原始选项类型、默认值、坐标范围与编码，不用有限 ERA5 字段替代在线定义。request_compiler 同时服务 Web 预览/创建与 CLI 的 compile、schema-check；schema_revision、editor_values 和 request_payload 必须一致。
少于 5 项的多选直接勾选，不提供文字输入；其他非变量枚举支持名称/ID 逗号输入，错误和歧义明确显示。较多变量仅搜索并勾选，不直接选入字符串；标签区常驻、默认一行，全部已选标签换行增高，清空恢复一行；候选区为 560px。
时间维度两行两列，适用组合输入框输入即展开、行内箭头、等宽弹层，支持外部点击/Esc/按钮关闭，保留数值、布尔与字符串类型。
请求状态、数据来源、拆分方式、账号状态和长单选字段使用统一卡片选单。支持方向键、Enter 选择和 Esc、Tab、外部点击关闭，禁用选项保留提示。
区域/点位使用有来源的离线 Natural Earth Plate carrée 世界参考图，框/标记联动坐标，处理日界线与零度，无效坐标不绘制伪造范围；不切换地图视图模式。
AI 为右栏的单一需求输入，配置集中在设置页；回填校验与撤销仍可用。宽屏右栏固定在视口上方并独立滚动，窄屏按单列排列。AI 和请求拆分与提交在右栏，手动规模在拆分方式与提交按钮之间。底部的请求详情默认隐藏，点击后在弹窗中显示请求编号、数据集及参数，可逐份切换。卡片视图默认显示已选值和字段名称，可切换到同一份请求的原始 JSON。参数未形成计划时可查看草稿。输出目录、浏览、覆盖和本地文件路径预览已取消。
支持按年、月、日和目标份数拆分请求。CDS 智能拆分要求明确的可分时间字段，优先按日期分组，日期不足时可细分时次。以有效时间点数量尽量均分，保留原字段类型与其余参数。份数超过可用时间点时拒绝整份计划。日期区间与 NCAR 原文件不支持智能拆分。预览、提交与规模估算复用同一份计划。
官方 costing 由用户手动刷新。拆分时逐份估算，只显示规模最大子请求及其对应上限，任一份超限单独提示。部分失败时显示成功份数并留空最大值。修改参数、拆分方式或份数后，旧结果标记过期。规模使用源站单位。占用达到 50% 变黄，达到 75% 变红，并提示过大的请求可能降低 CDS 排队优先级。[CDS 官方效率建议](https://confluence.ecmwf.int/spaces/CKB/pages/174856258/Climate%2BData%2BStore%2BCDS%2Bdocumentation)。
CLI 可用 --split smart --split-count N 预览或创建请求，HTTP 使用 split_strategy=smart 和独立的 split_count。

## 请求状态与恢复

本地排队、提交中、远端排队、远端处理中、链接已就绪、刷新中、失败、取消中、已取消、结果失效、待核实提交分别显示；源站不给处理百分比就不造进度。
提交成功立即保存远端 ID 与提交账号，后续使用同一账号查询。重启或迟到租约恢复时，有 ID 则继续监视；不明确的提交转入待核实，不盲目重发。可在官方请求页核实 ID 后关联，后台比对账号、数据集与参数。
查询失败退避重试，达到上限保留远端 ID；“继续监视”恢复查询原作业。只有用户明确重新提交已失败、取消或失效的请求，才清理当前远端绑定并发起新请求。
取消与就绪发布共用写事务；已接受的取消阻止发布结果。取消需源站确认，DELETE 的受理信息不等于取消完成。监视失败但远端可能运行时，仍可取消，不能直接删除本地记录造成失联。
全工作区调度租约及任务领取在事务中校验拥有者，换手后旧调度器不能领取；关停等已发操作保存 ID/状态后才释放租约。正常结束监视不删除已就绪远端结果。

## 结果交付

页面和 API 以结果列表表达 URL、官方提供的文件名、字节数、类型、可选有效期、最近查询时间；每请求可以有多个结果。SDK 当前 CDS 适配读取其单 asset，公共模型不限制为单结果。
队列顶部统计本地排队、远端排队、处理中和可用 CDS 账号。链接已就绪的请求在状态列展示结果总大小，所有结果均有大小元数据时才显示。

提交页可填写请求名称，留空使用数据集名称。一次提交的 CDS 拆分或 NCAR 多文件请求共享名称，队列和详情显示固定的份次，例如“ERA5 地表温度 · 2/6”。单份只显示名称，旧记录沿用原标题。筛选、翻页、删除和重试不改变原份次。

队列表格跟随页面宽度伸缩，每页显示 10 条，底部标明当前条目范围，复制反馈显示在总请求数旁。数据请求标题下按“来源 · 数据集 ID”展示。行和表头的复选框在悬停、键盘聚焦或选中时显示，触屏保持可见。表头全选仅选择当前页，部分选中时显示半选状态，翻页和筛选清空选择。批量和行内操作共用刷新、复制、重试、取消和删除条件。刷新会提前查询远端排队或处理中的请求，并更新就绪结果。未勾选时，刷新和复制作用于本页符合条件的请求。重试、取消和删除作用于勾选且符合条件的请求。批量删除需确认，部分失败会显示结果。重新提交使用圆形箭头，状态说明预留一行空间。点击请求名称打开详情。详情在居中弹窗中显示，长内容可在卡片内滚动。可用关闭按钮、Esc 或点击遮罩关闭，详情仍可复制单条结果；剪贴板受限时提示并保留可选中的原 URL。CLI task links 可按 ID 输出或列出全部就绪链接，支持 JSON。已就绪、取消、失效或确认结束的失败记录可以删除，最后一页删空后回退到上一页。
文件名/大小/类型取自结果元数据或对应 NCAR 文件响应头，不从选择参数推测字节或强制修改后缀。零字节和未知值分开显示。
链接不是永久地址；有效期缺省时显示未提供。不对数据文件发 GET 探测，也不代替下载器验证文件内容。用户可更新链接，源站作业/结果 API 明确不可用则标失效；不自动重新提交。
CDS 与 AI Key 通过 secrets.yaml 单独保存。账号和 AI 服务地址需使用无凭据的 HTTP(S) URL。校验响应、任务和账号错误、日志使用安全提示，不回显输入凭据或 SDK 异常原文。旧账号错误若有内容，在公开接口中返回统一提示。结果 URL 通过本地结果接口交付，带签名的完整链接不写普通事件或日志。

## CDS 账号

账号表显示今日使用次数和最后使用时间。今日使用次数按后台所在时区的自然日统计，每个 CDS 请求首次取得结果链接时记一次；刷新链接、连接测试和 NCAR 请求不计入。新记账事件在删除请求后仍可统计，旧事件仅回溯可确认账号的最后一次提交。API 地址在添加或编辑账号的表单中维护。

账号表支持逐行勾选和表头全选，桌面按悬停、聚焦或选中状态显示，触屏保持可见。批量测试并发检查已选账号，单个或批量测试的进度与结果都显示在对应账号行。删除入口位于单账号编辑弹窗，需要确认。

账号状态列将有绑定活动请求的可用账号标为「繁忙」，覆盖提交、远端排队/处理、刷新和取消。当前页面正在测试连接的可用账号也显示繁忙。绑定操作全部结束后显示「可用」。禁用与连接异常优先展示，调度仍依据账号的启用状态选取。

## AI 服务配置

设置页直接填入已保存的 AI API Key，可编辑后统一保存。API Key 右侧的测试使用输入框当前密钥、服务地址、模型、JSON 模式和代理设置发送最小请求。关闭 AI 服务后可清空 API Key 并保存。明文密钥由回环地址上的同源设置页读取。JSON 模式默认开启，测试与补全统一使用 OpenAI 兼容的 Chat Completions 请求格式，令牌上限使用 max_completion_tokens。GPT-6 Luna 采用无推理模式。

## CLI、HTTP 与设置

设置页的网络代理覆盖 CDS、NCAR 镜像和 AI 的出站请求。可选择关闭、使用系统代理或填写无凭据的 HTTP(S) 地址。系统模式读取后端环境或 Windows 系统代理。WSL 未继承代理时读取 Windows Internet 设置，将 NAT 下的回环代理地址映射到 Windows 网关。网络测试使用当前表单访问 CDS 公开目录。旧 cds_proxy 配置在读取时迁移到 network_proxy。


继续使用 ecmwf 命令和原包名；task create/watch/cancel/retry、request preview/compile 均调用应用服务。新增 task links、task refresh、task attach；不保留输出目录、覆盖、旧 enqueue/run 下载入口。
HTTP /api/v1/tasks 现在表示新请求记录；保留预览、账号、模板、字段、约束、costing、AI、settings 与 SSE。任务新增 links、refresh、attach；目录浏览 API 已移除，未知 API 不返回 SPA 页面。
requests 配置含 max_workers、poll_interval、max_retries、retry_delays；并发指同时执行的后台 API 操作，远端处理中不持续占用网络线程。同进程 PATCH /api/v1/settings 在保存成功后应用此次修改。并发上限用于后续领取，轮询间隔和退避用于下次安排，已有操作和已安排的等待继续执行。默认查询重试次数用于新建请求，已有请求保留各自上限。独立 CLI 的 config set 写盘后由后台服务重启读取。非法配置在写盘前拒绝。
设置页右上角统一保存网络代理、AI 服务与请求监视。测试独立运行。保存只提交修改的设置，API Key 写入 secrets.yaml。请求监视可配置状态查询间隔和新请求默认查询重试上限。重试设为 0 时查询失败后不自动重试。并行上限与退避等待由后台配置管理，数据库路径由启动参数或应用配置指定。
不含预约下载、暂停、全局停止、自动下载器 RPC 或多用户认证；服务只需回环监听。

## 存储与支持范围

SQLite WAL 保存 request_tasks、request_events、调度租约、账号运行状态和模板；通过 create_all 只创建缺失表。
原 tasks/task_events、账号、其他配置和现有下载文件保留，不导入新请求队列、不清空、不重建；旧记录不伪装成结果链接。没有 Alembic 或自动 ALTER TABLE，后续结构变更须另行确认处理方案。 新批次使用独立的 request_batch_items 表，名称、份次和原总份数与请求在同一事务写入。
本轮已移除当前 app.yaml 的旧 download 分组，保留其他配置并改用经过校验的 requests；secrets.yaml 未改写，专业下载器的目标目录由下载器管理。
Linux/WSL 为当前验证环境，Windows 原生文件锁/权限与真实后台运行仍未验收。不能用字段分类覆盖或模拟测试替代全部数据集组合与真实源站验收。
应用配置以同目录临时文件写入并同步后原子替换。并发更新串行读取并合并最新磁盘值，保存失败保留原配置和运行值。一次保存同时更新 AI 配置和 Key 时，若凭据写入失败会恢复原应用配置。应用配置和凭据各自原子替换。

## 当前验证证据

2026-10-28（Asia/Shanghai）：148 个不同的相关后端测试分批通过，TypeScript/Vite 构建通过，25 项页面功能断言通过；页面错误、自动 costing 和数据文件 GET 均为零。页面提交/失败/取消/关联/刷新使用隔离模拟，真实字段、常规预览、结果详情和实际链接参与检查；剪贴板交互使用浏览器内测试替身，未作系统剪贴板或视觉验收。
真实 CDS 小请求：ERA5 single levels，2m_temperature，2024-01-01 00:00 UTC，area=[31,120,30,121]，NetCDF。远端 successful，本地 completed，官方结果元数据 25171 bytes；重启并更新链接仍使用同一远端 ID，没有新增提交或下载文件。
真实 NCAR AWS/GDEX：各列出 62 个 2024-01 地表文件，并对 2m temperature 原文件获取 HEAD 响应，均得到一个 HTTPS 链接与 1134576716 bytes，账号关联为空；未下载这两个大文件。
运行实例保留这三个真实链接请求供用户查看。详细记录在 TASK-32、TASK-9；所有完成状态与验收勾选仍由用户决定。

TASK-13、14 的定向证据记录在各自任务。配置验证使用独立目录与故障注入。凭据验证使用虚构 Key、Token 和客户端响应。
