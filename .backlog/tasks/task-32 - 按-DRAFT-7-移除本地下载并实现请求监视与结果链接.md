## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
用户已确认软件只提交请求并监视处理状态，向专业下载器交付结果链接；移除本地数据传输与 ARCO NetCDF 导出。当前 Worker、存储、CLI/API 和界面均以本地输出文件为完成条件，需一致改造并保留既有用户数据。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 CDS 单独提交并保存远端 ID/账号，重启按 ID 监视；未知提交不自动重发，提供核实入口
- [ ] #2 结果为真实 URL 和可用元数据；列表可表达多结果，支持复制、API/CLI 输出与手动更新；失效不自动重提
- [ ] #3 NCAR AWS/GDEX 只返回真实文件链接，ARCO 本地导出与数据传输代码不可调用
- [ ] #4 Web、CLI、API 去掉输出目录/覆盖/传输字节等下载操作，保留字段、AI、拆分、手动规模
- [ ] #5 调度租约、迟到恢复、取消/完成与查询重试有一致状态，不因网络错误重复提交
- [ ] #6 新表只通过 create_all 创建，原表/账号/配置及下载文件不清空或重建
- [ ] #7 相关模拟测试、构建与真实小请求到链接验收分开报告，禁止读取数据文件体；保留未验证范围
- [ ] #8 更新现有需求与任务适用范围；任务交用户验收，不代设 Done 或勾选验收
<!-- AC:END -->
