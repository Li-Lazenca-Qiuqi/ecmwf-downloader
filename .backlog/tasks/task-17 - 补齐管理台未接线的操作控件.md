- [ ] #6 连接、内置调度器状态、后台 API 并发、状态查询间隔、查询重试和 AI 启用取实际响应，异常和未知状态不显示为健康（承接 TASK-18）
- [ ] #7 添加与编辑账号使用居中卡片弹窗，保持表单与保存逻辑，内容较长时在卡片内部滚动
- [ ] #8 账号列表以表格展示，弹窗直接显示邮箱、API Key 和可修改的默认预填 API 地址，不使用更多信息折叠区
- [ ] #9 连接检查使用官方认证接口并返回脱敏原因，检查结果不计入请求失败次数，也不自动禁用账号

<!-- SECTION:PLAN:BEGIN -->

2. 单队列接入真实统计、筛选分页与任务详情；创建页折叠高级配置和 AI，保留可编辑请求参数与预览。
3. 简化账号和只读设置，移除无效控制及固定健康文案，补充加载/错误状态和窄屏布局。
