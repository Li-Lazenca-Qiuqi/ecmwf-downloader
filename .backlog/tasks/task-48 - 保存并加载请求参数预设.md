## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
源自 DRAFT-8。重复提交相似科研请求时，希望复用上一套参数。复用项目已有模板服务和存储。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 提交页可按名称保存和加载预设，包含来源、数据集、所选参数和拆分设置，页面刷新和服务重启后仍可加载。
- [ ] #2 加载只回填可编辑表单，使用当前数据集字段重新校验。字段或镜像文件变化时，提示重新选择受影响内容。
- [ ] #3 预设不包含账号、凭据或结果链接。加载后由用户发起提交，沿用提交页当前的账号选择规则。
- [ ] #4 加载预设弹窗可确认删除选中的预设，删除失败时保留预设并显示错误。
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
在提交页增加命名保存和加载，沿用模板接口。用在线字段校验回填，保护旧模板与编辑状态。

将预设操作移到提交按钮左侧，移除返回队列。验证 Enter 保存预设不会提交请求。

将请求详情并入同一操作区，用等宽等高的四列，空间不足时改为两列。

将保存成功反馈移到视口右下角，独立显示并自动收起。

将加载预设替换成大弹窗，先浏览预设参数，再确认回填，验证取消、空状态和回填。

加载预设优先复用当前有效字段缓存，缺少缓存时使用普通字段查询，保留校验和失败后的表单内容。

复用现有模板 DELETE 接口，在加载弹窗内确认删除，更新预设列表并验证取消和失败。
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Playwright 使用模拟字段与真实本地模板 API，保存、刷新、回填并验证删除字段选项后提示重新选择。API 验证容器重新打开后仍能读取，且同名旧模板不会被预设覆盖。

预设操作移到提交按钮左侧，移除返回队列。Playwright 验证按钮顺序、按 Enter 保存预设不会提交请求，以及加载后正常回填。生产前端构建通过。

请求详情与预设、提交共用操作区。生产构建通过。Playwright 验证 1440px 四按钮同一行、390px 两列，尺寸一致且详情弹窗可正常打开与关闭。

保存成功改为右下角浮层提示，3.5 秒自动收起。生产构建通过，Playwright 验证定位、消失、保存和加载。

加载预设改用双栏弹窗。生产构建通过。Playwright 使用模拟字段和预设验证浏览、卡片与 JSON、取消保留编辑、字段刷新失败后重试、确认回填、窄屏及空状态。

加载预设弹窗的参数卡片改为单列。生产前端构建通过，Playwright 使用长短参数验证单列堆叠和 JSON 切换。

预设回填复用 5 分钟内有效字段缓存，缓存缺失时用普通字段查询，避免强制刷新。生产构建通过，Playwright 模拟接口验证命中缓存时无字段请求（一次约 180ms）、缺失、失败保护和重试。

弹窗可删除选中的预设，确认后复用模板 DELETE 接口。生产构建通过，Playwright 用模拟接口验证取消、失败保留、删除后切换和删除最后一条的空状态。

用户确认已试用预设功能，保存、预览、加载和删除一起提交。
