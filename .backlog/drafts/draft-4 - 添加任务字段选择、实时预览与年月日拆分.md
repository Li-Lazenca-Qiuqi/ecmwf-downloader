## 背景与目标

2026-10-26 用户要求修改添加任务界面：输入或选择数据集，获取全部可选字段，通过字段控件选择参数，实时显示请求预览；输出目录增加浏览，支持按年/月/日拆分；AI 补全放到数据集下方、字段上方。

本需求替换此前以原始 JSON 输入为主的创建界面，继续沿用已确认的单一队列、创建后自动入队和取消规则。此前账号页修改与认证修复保留，不混入本需求；TASK-17 仍待用户验收。

## 页面与交互

1. 数据集：支持手动输入 ID 与选择数据集。加载该数据集字段后显示加载结果、字段来源和错误；不把内置常用数据集当作支持范围上限。切换数据集后清理旧选择、旧预览和过期 AI 结果，避免混用不同数据集参数。
2. AI 补全：固定放在数据集下方，显示自然语言输入和生成按钮。使用当前数据集的完整字段信息生成建议，结果回填同一套控件及实时预览。未启用或未配置时说明原因，不影响手动选择。未知字段、不合法选项或不匹配类型明确提示，不能悄悄写入不可见参数或直接创建任务。
3. 字段选择：获取在线元数据中全部可用字段及选项，不截取前若干项，不用 ERA5 固定字段伪装其他数据集。枚举用单选、多选或可搜索列表，选项多时支持搜索与批量选择；数值、布尔、自由文本和 area 等没有枚举的字段使用对应的结构化输入控件。保留字段原始类型与值，日期不因界面显示转换而丢失前导零。主流程不要求输入 JSON。
4. 请求预览：桌面与字段区同时显示只读 JSON 参数及当前数据集，选择和 AI 回填立即同步。窄屏按单栏排列，保留清楚可达的预览区。输出路径、拆分后的任务数量及文件名可通过本地预览同步更新，较频繁的修改可防抖；预览不写入任务，也不等同 CDS 远端下载校验。
5. 输出与拆分：提供可编辑的输出目录和浏览按钮；拆分下拉选择不拆分、按年、按月、按日。展示即将生成的任务数量；参数不完整或非法时给出原因，不创建部分任务。只有添加并下载一个提交入口，提交期间防止重复点击。

## 字段来源与约束

- 在线字段和选项通过官方 Datastores 元数据能力获得，修正当前元数据转换可能遗漏类型、枚举或嵌套字段的地方。明确在线结果、已缓存结果和失败，不静默以固定字段宣称查询成功。
- CDS 提供相应参数约束时，用于提示或更新合法选项；条件不足、约束查询失败或某类控件不支持时必须说明边界，不伪造远端校验通过。
- 不能保证所有 CDS 自定义控件立即完整兼容；遇到尚不支持的字段，要显示字段名和原因，不能直接隐藏后继续提交一个缺少用户选择的请求。优先以现有 ERA5 请求和至少一种不同字段类型的元数据样例验证，不以单个样例代替通用支持证明。

## 目录浏览

- 浏览的是运行后端的机器目录：Linux 服务器经 SSH 访问时选择服务器路径；当前 WSL 实例选择 WSL 可见路径。不能把浏览器选到的本地文件夹名当作远端绝对路径。
- 默认从配置的输出目录开始；不存在时定位可访问的上级目录。支持进入子目录、返回上级、显示当前路径和选择当前目录，也允许直接填写路径。
- 目录接口仅枚举目录与路径信息，不读取文件内容，不返回凭据或配置内容，不创建、删除、移动目录。权限不足、路径不存在、路径不是目录时返回明确且脱敏的错误；保留用户已填的输出目录。
- Windows/Linux 采用各自合法的路径和根目录处理；不能据 WSL 通过就声称 Windows 原生产品已验收。

## 年月日拆分

- 后端增加 day 拆分策略，并在 CLI/API/预览/创建保持相同语义；不拆分、按年、按月保持兼容。SQLite 当前以文本存拆分策略，优先不改表结构，不引入 Alembic 或重建数据库。
- 按年：每个所选年一个任务；按月：每个所选年/月组合一个任务；按日：每个有效年/月/日组合一个任务。其他参数完整保留，文件名包含相应日期以便区分。
- 按日需要数据集有明确可用的日期维度；不适用的拆分选项禁用并说明原因，不擅自给月平均等数据集补日字段。
- 处理闰年、2 月和大小月。跨月份选择的日期集合中过滤不存在的日期并在预览明确提示数量，不能生成 2 月 30 日这类任务；若选择后没有有效日期则阻止提交。非法月份、超出日期范围和缺失维度给出明确错误。
- 预览与最终创建使用相同拆分逻辑，任务数、参数和文件名一致，预览不产生下载。新任务统一 queued，由已有消费者按并发上限处理。

## 当前差距与任务关联

当前 RequestPage 为 JSON 编辑、AI 在底部折叠、只有年/月拆分且没有目录浏览；DatasetService 会静默回退固定字段。现有 Datastores adapter、字段类型模型和约束 API 需要核对扩展。

本稿确认后再调整 TASK-19：其旧“取消动态表单联动”的范围由本稿取代，保留来源透明和不得伪造校验的要求；请求页与目录/按日能力按独立工作单元登记或拆分任务。TASK-17 中已实现的账号页及原管理台验收不自动完成或取消。其他可靠性待办不因本需求自动消失。

## 验收标准

- 数据集加载后显示元数据返回的全部可选字段，至少覆盖可搜索的枚举多选、单选、数值、布尔和区域字段；不依赖 JSON 手输。
- AI 区域位于数据集下方，回填值在控件与只读预览一致；切换数据集或延迟响应不会恢复过期参数。
- 请求参数实时预览；本地拆分预览与创建结果一致，不写任务或声称通过远端下载校验。
- 后端目录浏览可进入、返回和选择，错误可见，无凭据/文件内容泄露和文件系统修改；选择结果实际进入请求的 output_dir。
- 年/月/日拆分覆盖跨年、闰年 2 月、大小月、缺失维度、不适用数据集和没有有效日期；旧策略回归通过，不改用户数据库与下载文件。
- 使用隔离目录与模拟元数据做定向后端、CLI/API 和前端功能验证，执行 TypeScript/Vite 构建。真实下载另按 TASK-9 验收；不自动视觉验收，不自动提交 Git。
